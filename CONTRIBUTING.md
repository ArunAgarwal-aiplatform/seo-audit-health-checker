# Contributing to SEO Audit Health Checker

Thanks for your interest in contributing.

## How to contribute
1. Fork the repository.
2. Create a new branch for your change.
3. Make your updates with clear, focused commits.
4. Run checks locally before opening a pull request.
5. Submit a PR with a short description of what changed.

## Development guidelines
- Keep the code pure Python and dependency-light.
- Preserve compatibility with `.txt`, `.md`, `.html`, and `.htm` files.
- Write clean, readable, and well-documented code.
- Prefer small, focused changes over large unrelated edits.

## Suggested checks
- Run the script on sample files.
- Verify output formatting and scoring.
- Test any new rules with both short and long content examples.

## Pull request expectations
Please include:
- A clear summary of the change.
- Any relevant sample input/output.
- Notes on tests or validation performed.

## Code style
- Use descriptive variable names.
- Keep functions focused on one task.
- Avoid unnecessary dependencies unless strongly justified.

## Reporting issues
If you find a bug, please include:
- The file type you tested.
- The exact input that caused the issue.
- The expected behavior and actual behavior.

Thank you for helping improve the project.
